# CarMediaHub SDK

CarMediaHub SDK는 플러그인 매니페스트, 수명 주기 계약, 플랫폼 컨텍스트, capability API와 격리된 데이터 접근 규칙을 정의합니다.

언어: [English](readme.md) · [简体中文](readme_zh.md) · 한국어

플러그인은 Core 내부 모듈을 가져오지 않고 공개 계약을 통해 플랫폼 기능을 사용합니다.

## 제공되는 기능

- `PlatformContext`: 사용자, 조직, 플러그인 설치 인스턴스, 장치, 언어, 시간대, 테마, 밀도, 진입 방식과 표시 컨텍스트를 제공합니다.
- `onContextChanged`: Core의 공통 설정이 바뀌면 플러그인이 별도의 언어 또는 표시 설정 시스템 없이 UI를 갱신할 수 있습니다.
- `normalizeLocale`, `localeFallbacks`, `localize`: 공통 언어 별칭과 요청 언어 -> 언어 계열 -> 영어 순서의 문구 fallback을 제공합니다.
- 데이터, 미디어, 기록, 카탈로그, 표시, 작업, 알림, 네트워크 및 이벤트를 설치 인스턴스 권한으로 제한하는 Capability API를 제공합니다.
- `WorkerClient`와 Wire Protocol을 통해 Broker의 논리 경로를 사용하며 공개 포트, 데이터베이스 연결, 호스트 경로 또는 세션 Cookie에 접근하지 않습니다.
- `Memory Runtime`은 계약 테스트용이며 운영 저장소나 미디어 실행기를 의미하지 않습니다.

## 실행 경계

Manifest는 권한 요청이며 임의의 시스템 호출 인터페이스가 아닙니다. 플러그인은 Shell 명령, 호스트 경로, 임의 환경 변수, 데이터베이스 DSN 또는 선언하지 않은 권한을 제출할 수 없습니다. 인증, 범위, 권한, 자원 제한과 오류 비식별화는 Core가 담당하고 플러그인은 SDK의 논리 API만 사용합니다.

## 버전과 언어

v0 계약은 `en`, `zh-CN`, `ko`를 지원합니다. 플러그인은 Core가 전달하는 언어, 시간대와 표시 컨텍스트를 상속합니다. 플러그인은 업무 문구 번역을 제공할 수 있지만 플랫폼 전체 설정을 별도로 만들면 안 됩니다. 프로토콜과 오류 규격은 [`spec/v0`](spec/v0/readme_ko.md)에 있습니다.

## 초안 계약

검토 단계의 v0 계약은 [`spec/v0`](spec/v0/readme_ko.md)에 있습니다. 실행 중인 Core 없이도 매니페스트 검증과 안정적인 오류 식별자를 정의합니다.
